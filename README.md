# Image Caption Generator using BLIP

This project implements an AI-based Image Caption Generator that automatically
generates meaningful textual descriptions for images using a transformer-based
BLIP (Bootstrapped Language-Image Pretraining) model.

The project combines Computer Vision and Natural Language Processing to
understand visual content and convert it into human-readable captions.

---

## Features
- Generates captions for input images automatically
- Uses pretrained BLIP transformer model
- Simple and easy-to-run Python implementation
- Works on real-world images

---

## Technologies Used
- Python
- Hugging Face Transformers
- PyTorch
- Computer Vision
- Natural Language Processing (NLP)
- Matplotlib
- PIL (Python Imaging Library)
